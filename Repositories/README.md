# Repositories

Whole example sets, copied as their authors structured them. Canvases reference Markdown notes and images by relative path, so keep each folder intact.

| Set | Source | Licence |
|---|---|---|
| `Candy/` | [TfTHacker/obsidian-canvas-candy](https://github.com/TfTHacker/obsidian-canvas-candy) | MIT, `Candy/LICENSE` |
| `JSONCanvas/` | [obsidianmd/jsoncanvas](https://github.com/obsidianmd/jsoncanvas) | MIT, `JSONCanvas/LICENSE` |
| `Hesprs/` | [Hesprs/JSON-Canvas-Viewer](https://github.com/Hesprs/JSON-Canvas-Viewer) | MIT, `Hesprs/LICENSE` |

Each set's `LICENSE` is its upstream's, copied on 10 Oct 2026; keep it with the set wherever the set is copied or bundled. A set is only added here with an open-source licence, and only the files that licence covers: Candy's stock photos (Unsplash and Pexels) and its brand logos are left out. In their place:

- `Candy/Assets/nasa-*.jpg`, for the Apollo timeline: NASA photos AS11-40-5903, 6900556 and AS15-86-11603 from [NASA's image library](https://images.nasa.gov), public domain, resized;
- `Candy/Assets/portrait-*.jpg`, for the organisational chart: eleven portraits of fictional people, made for this repository with ChatGPT image generation and offered under CC0 1.0. With thanks to [Novoda](https://www.novoda.com) for the image generation, and to [Jake Lee (@jakelee_art)](https://www.instagram.com/jakelee_art/), whose dreamy gradient portraits inspired the style.

The brand logos on the stickers stencil have no replacement, so those four image nodes point at files that aren't here.
