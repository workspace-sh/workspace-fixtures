# Canvas

24 JSON Canvas (`.canvas`) files, each a single document. The name prefix says where it came from:

| Files | Source | Licence |
|---|---|---|
| `candy-*.canvas` (22) | [TfTHacker/obsidian-canvas-candy](https://github.com/TfTHacker/obsidian-canvas-candy) | MIT |
| `official-sample.canvas` | [obsidianmd/jsoncanvas](https://github.com/obsidianmd/jsoncanvas), the spec's sample | MIT |
| `hesprs-demo.canvas` | [Hesprs/JSON-Canvas-Viewer](https://github.com/Hesprs/JSON-Canvas-Viewer), its demo: every node type and edge style | MIT |

Each licence's text is in the matching set's folder in [`../Repositories/`](../Repositories/). Some file nodes point at files that aren't here; for most of those, use the full sets in `Repositories/`. The stock photos in `candy-organizational-chart` and `candy-apollo-missions-timeline` were replaced with public-domain and CC0 images, and the brand logos in `candy-stencil-stickers` aren't anywhere here (see `Repositories/README.md`).
